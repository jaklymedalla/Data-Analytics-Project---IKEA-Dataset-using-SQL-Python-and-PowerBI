# Data-Analytics-Project---IKEA-Dataset-using-SQL-Python-and-PowerBI

IKEA Data Analytics Project


Project Overview

This project delivers an end-to-end data analytics solution using an IKEA dataset. The goal is to analyze product performance, pricing strategies, and customer segmentation to provide actionable business insights. The project follows a structured data lifecycle—progressing from business requirements gathering to a final interactive dashboard.

Analytics Workflow


1. Business Requirements Document (BRD)

• Objective: Understand stakeholder goals, key performance indicators (KPIs), and target business questions.
• Focus: Aligning technical development with business outcomes such as revenue optimization and product category growth.

2. Dataset Review (Excel)

• Objective: Initial data profiling and structural validation.
• Approach: Utilized Microsoft Excel to quickly scan column types, check for data completeness, and map out relationships prior to ingestion.

3. Data Cleaning & EDA (SQL)

• Objective: Efficient data transformation and exploratory data analysis.
• Why SQL?: SQL allows for highly efficient schema exploration, fast querying, and rapid data cleansing (handling null values, standardizing text strings, and deduplication).
• Key Steps:
	• Filtering out erroneous or out-of-scope records.
	• Aggregating key metrics to understand distribution patterns.

4. Data Segmentation (Python & Pandas)

• Objective: Advanced behavioral and product segmentation.
• Why Python?: Given the size and complexity of the dataset, Python's pandas library was leveraged to handle memory-efficient data processing, apply logical grouping, and run algorithmic segmentations.
• Key Steps: Categorizing products and performance tiers into distinct analytical buckets for deeper cross-filtering.

5. Visualization & Reporting (Power BI)

• Objective: Interactive dashboard delivery for business stakeholders.
• Features:
	• Clear visual tracking of core revenue metrics and customer segments.
	• Optimized user experience utilizing dynamic bookmarks and selection panes to easily toggle between independent analytical views (e.g., Customer insights vs. Revenue trends) without interrupting user filter states.

Tools & Technologies Used

• Documentation: Business Requirements Document (BRD)
• Exploration: Microsoft Excel
• Data Engineering: SQL (Structured Query Language)
• Data Science: Python (pandas, numpy)
• Business Intelligence: Microsoft Power BI
